# Write the IAMC native regions in yaml as defined in https://github.com/IAMconsortium/common-definitions

`write_native_regions_yml` write a yaml file with the native regions.

## Usage

``` r
write_native_regions_yml(filename = NULL, model = "WITCH 5.0", n = "witch17")
```

## Arguments

- filename:

  yaml filename to write

- model:

  model version

- n:

  Witch region definition, as defined in witchtools.
