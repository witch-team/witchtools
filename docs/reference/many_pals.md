# Many color palettes

Creates thematic palettes for WITCH results and other

## Usage

``` r
many_pals(component = NULL, variant = NULL, theme = NULL, include_names = NULL)
```

## Arguments

- component:

  palette's component (`fuel`, `region`).

- theme:

  A palette theme (`witch-plot` (default)).

- restrict_names:

  only return the corresponding named values.
